# Web UI 设计细化

状态：实施前的 UI 设计稿。仅新增设计文档，不代表已实现页面。业务规则以本 change 的 delta specs 为准。

## 1. 整体布局和样式

- 保留 `/admin` 现有标题、同步状态栏、左侧导航、右侧编辑区域和模块顺序。
- 保留现有浅色背景、白色面板、系统字体、深色主按钮。面板内间距 18px、表单字段间距 14px、输入和按钮高度 40px、圆角 6～8px，沿用现有 CSS。
- 本次只修改操作计划、巡视模板相关入口与弹窗，以及大屏操作模块的空态；许可、其他、休假、节假日和巡视实例管理流程不重做。
- 不将导入、生成和导出铺成一整排行内按钮。相近操作位置固定，危险操作在“更多”菜单底部单独分组。
- 文案统一：操作计划使用“子任务”，巡视模板使用“周期项”；“重新生成实例”只指实例替换，“导入子任务 / 导入周期项”只指模板明细覆盖。
- 实施后不得保留一个叫“刷新实例”的旧入口和另一个叫“重新生成”的新入口，使用户无法判断两者差别。

## 2. 操作计划列表

### 2.1 页面结构

```text
操作计划
当前大屏计划：计划 A                      已启用
日期 [2026-10-25]  [昨天] [今天] [显示全部] [新增计划]
                                         [重新生成实例]
大屏   计划（名称 / 说明）   类型   子任务数   状态   操作
 ●     计划 A               循环      8      已启用  详情 修改 更多▾
 ○     计划 B               一次性    4      已禁用  详情 修改 更多▾
```

顶部摘要和选中行必须与服务端已保存选择一致。

- 新增“大屏”单选列；计划名称和说明放在同一个单元格内，名称在上、说明在下，避免横向无限加列。
- 状态使用文字“已启用 / 已禁用”，不只靠颜色。禁用行文字可以弱化，但单选、状态和操作按钮保持清晰可读，不整行禁用。
- 当前大屏计划摘要位于日期工具条之前，选择对象被日期筛选隐藏时仍显示名称；辅助提示“当前展示计划不在本次筛选结果中”。
- 所有 radio 组成一个“大屏展示计划”单选组，标签包含计划名称。点击单选不触发详情或整行其他动作。
- 表格沿用最小宽度约 820px，操作列控制在约 210px；窄屏只允许表格容器横向滚动，不能撑宽整个页面。

### 2.2 “更多”菜单

固定顺序：

1. 重新生成实例（与顶部按钮打开相同流程，锁定当前行计划）。
2. 导入子任务。
3. 导出计划 XLSX。
4. 分隔线。
5. 启用 / 禁用。
6. 删除计划（红色，沿用原删除确认）。

行内继续保留“详情”“修改”；不把计划删除放在生成或导入按钮旁边。菜单须能通过键盘打开和选择，Escape 或点击外部关闭，且不能被表格滚动容器裁切。

### 2.3 大屏单选交互

| 阶段 | UI 行为 |
| --- | --- |
| 初次加载 | 摘要显示“正在读取大屏选择…”，radio 暂不可用；不能先假定第一行已选再闪回 |
| 正常 | 显示服务端选择，首次默认值由服务端全局初始化；日期过滤不能重置选择 |
| 点击另一个 radio | 不二次确认；新目标旁显示“切换中…”，同组暂禁用，旧已保存选择保持可识别 |
| 保存成功 | 更新单选及摘要，提示“已切换为「计划 B」，已通知大屏刷新” |
| 保存失败 | 保留旧选择，摘要旁显示“切换失败：原因”，恢复可操作，不假装已切换 |
| 请求结果不明确 | 提示“切换结果未确认，请刷新查看”，重新读取服务端选择后再展示最终状态 |

- 禁用计划仍可被选择；选择不会启用它。摘要说明“计划已禁用，大屏显示无可展示计划”。
- 删除、禁用或没有当前实例时不自动选择别的计划；保留服务端返回的失效状态，不在前端自行回退第一行。
- 不增加浏览器本地开关或另一个“保存展示选择”按钮。

## 3. 重新生成实例

### 3.1 入口与弹窗

- 顶部“重新生成实例”：打开单计划表单，计划下拉初始显示“请选择计划”；从全量操作计划读取选项，不受当前日期过滤限制。
- 行内“更多 → 重新生成实例”：计划已锁定为该行，仅显示计划名称，不允许填完字段后悄悄换目标。
- 取消旧的“全部操作计划”选项。禁用计划和无子任务计划不能提交生成，并显示具体原因“计划已禁用，请先启用”或“请先添加子任务”。
- 弹窗标题“重新生成实例”，宽度 640px 上限；同一弹窗内完成“填写安排 → 确认替换”两步，不叠加两个可交互的遮罩弹窗。

### 3.2 周期性计划表单

```text
重新生成实例
操作计划       [计划 A                         ▾]
起始子任务     [B 操作 · 时长 4 小时            ▾]
子任务开始时间 [2026-10-25 10:30]
生成截止时间   [2026-10-26 00:00]
日历规则       跳过周末 / 跳过节假日（只读摘要）

本次从 B 操作开始，保留任务间空档。
只生成开始时间早于截止时间的任务，任务可能在截止后结束。

注意：将替换该计划全部未开始的自动安排，包括本次时间范围之外的旧安排。
进行中、已完成、已取消及人工维护的实例会保留。
                                [取消] [下一步]
```

| 字段 | 控件和规则 |
| --- | --- |
| 操作计划 | 顶部入口为必选下拉，行入口为只读目标；选项显示名称及一次性/有限循环/无限循环 |
| 起始子任务 | 必选下拉，按计划时间轴顺序（偏移、排序）排列；显示内容和时长，不要求用户填写或换算偏移；重名任务附序号区分 |
| 子任务开始时间 | 必填 datetime-local，分钟精度；统一按北京时间解释，旁边标注“北京时间” |
| 生成截止时间 | 必填 datetime-local；必须晚于开始时间，不把用户填错的结束值静默改为开始值 |
| 日历规则 | 展示所选计划的跳过规则，只读；需要改变时到计划编辑，不在本次生成表单修改 |

- 子任务未默认选定，用户必须明确选择；起始任务改变时，保留已填写实际时间，含义始终为新选择子任务的开始时间。
- 开始时间初始取管理端当前选定日期的 08:00；不读取为“本次实际时间”的旧周期零点。该默认值在进入确认步骤前可修改。
- 一次性计划的默认截止为开始时间加完整周期时长；有限循环优先使用计划结束时间（晚于开始时才使用，否则留空要求填写）；无限循环默认到开始日期次日 00:00。切换计划清空子任务并重置时间默认值。
- 用户修改开始时间后，如果截止时间变得无效，保留填写值并在字段下报错，不偷偷顺延截止时间。
- 不增加周期零点输入、已执行时长输入、额外偏移输入或手工循环间隔输入。

### 3.3 一次性计划表单差异

- “起始子任务”替换为只读“生成起点：周期零点（整轮开始）”。
- 时间字段标签改为“整轮开始时间”；输入值对应周期零点。
- 保留截止时间与相同的开始时间筛选规则；不允许选择 B 跳过本轮较早任务。
- 提示改为“按计划定义从整轮起点生成，不修改计划原始开始时间”。

### 3.4 确认步骤

同一弹窗切换标题为“确认重新生成”，展示计划名称、计划类型、起始子任务或“周期零点”、实际开始时间、截止时间和日历规则。主提示固定为：

> 将替换计划「计划 A」全部未开始的自动安排，包括本次生成范围之外的旧安排。进行中、已完成、已取消及人工维护的实例会保留。

- 按钮为“返回修改”和“确认替换并生成”；确认按钮采用现有危险操作样式。
- 返回修改保留输入。不要再叠加第三次确认、勾选同意或要求输入计划名称。
- 不在确认页伪造新增、删除条数；本轮不为此引入完整预生成服务或排程预览表。

### 3.5 提交与结果

| 结果 | UI 行为 |
| --- | --- |
| 正在提交 | 按钮显示“正在重新生成…”，阻止重复提交；禁用返回、关闭和遮罩关闭，不承诺可取消已发出的写入 |
| 成功 | 关闭弹窗、刷新列表，持续显示“已重新生成「计划 A」：清理 M 条，新增 N 条，跳过 K 条”至下次同类动作 |
| 成功但新增为 0 | 明确显示“清理 M 条，新增 0 条；所选时间范围未产生可生成任务”，不显示成失败或隐藏清理结果 |
| 服务端明确失败并回滚 | 留在弹窗，保留输入，显示“生成失败，原安排已保留：原因”，可返回修改或重试 |
| 网络中断或超时 | 显示“生成结果未确认，请刷新后检查”；不自动重试，也不声称原安排一定未变 |

## 4. 计划导入

### 4.1 操作和巡视入口

- 操作：列表行“更多 → 导入子任务”。目标为该行计划；不在新增计划或尚有未保存编辑的计划表单里导入。
- 巡视：保留现有“周期项管理”入口和“导入模板下载”，将“批量导入”统一命名为“导入周期项”，仅选择 `.xlsx`。
- 两者使用一致的导入弹窗。已打开周期项管理时，导入作为该界面的一个步骤，背后的管理内容暂停交互，不额外叠加一个确认弹窗。
- 表单标题分别为“导入操作子任务”“导入巡视周期项”，目标计划名称始终只读可见。

### 4.2 导入弹窗结构

```text
导入操作子任务
目标计划：计划 A                         当前 8 项
[下载导入模板]             [选择 XLSX 文件]
已选：计划A-子任务.xlsx
校验通过：共 6 项，以下预览前 5 项
序号 | 任务内容 | 开始偏移（分钟） | 持续时间（分钟）
  1  | A 操作   |       0          |       120
  2  | B 操作   |     180          |        60

将用文件中的 6 项覆盖当前全部 8 项。
计划基本信息及已生成实例保持不变。
                                [取消] [确认覆盖]
```

- 选择文件后先解析、校验全部导入行；预览只显示前 5 项，不能只验证预览行。
- 预览区域最多 240px 高，长字段在弹窗内换行或局部滚动，不撑开整页。
- 显示文件名、目标计划、原明细数量和有效导入数量。空文件或无有效明细报错，不用空文件清空计划。
- “确认覆盖”只在全量校验通过后启用；这个带目标与替换数量的预览页本身就是覆盖确认，不再追加重复确认。
- 重新选文件立即清除上一个文件的预览与通过状态；相同文件修复后重新选择也必须重新校验。
- 字段错误在文件区域显示，包含工作表、原始行号、字段名和原因；缺少/重复表头在解析数据前报错。额外列按该导入格式的定义处理，不猜测相近表头。
- 文件中即使有“计划信息”页，也只用于导出阅读，导入不覆盖当前计划基本信息。

### 4.3 提交和反馈

- 保存中显示“正在覆盖…”，禁用重复提交与关闭。
- 成功关闭导入步骤，刷新目标计划详情和列表统计，显示“已覆盖导入 N 项；已生成实例未修改”。
- 操作计划如需更新实例，用户再独立进入“重新生成实例”，不在导入成功后自动生成或自动改选大屏计划。
- 明确写入失败时保留文件和校验结果，原数据由服务端事务保护；结果不明确的网络错误与生成采用同样措辞，不自动重放写入。

## 5. 单计划导出与文件布局

### 5.1 页面入口和反馈

- 操作列表“更多 → 导出计划 XLSX”；只读计划详情也可在标题区域提供同名按钮。
- 巡视列表将行内动作整理为“详情 / 周期项管理 / 修改 / 更多”，把启停、导出和删除放入更多菜单；详情和周期项管理工具条可提供“导出计划 XLSX”。
- 所有入口调用同一个单计划导出动作，导出的都是完整计划定义，不是当前过滤行、当前预览页或当前已生成实例。
- 启用、禁用或无子任务的计划均可导出；空计划导出基本信息及带表头的空明细页。
- 只导出服务端已保存数据，不导出计划编辑弹窗内未保存的内容。
- 点击后原按钮显示“导出中…”并禁用；成功发起下载后提示“已生成导出文件”；失败在入口附近提示“导出失败：原因”。不要宣称文件已成功写入用户磁盘。
- 文件名采用 `操作计划-计划名-YYYYMMDD.xlsx` 或 `巡视计划-计划名-YYYYMMDD.xlsx`，清理文件名不允许的路径字符；不增加全局或批量导出入口。

### 5.2 工作簿约定

| 工作表 | 固定内容 |
| --- | --- |
| 计划信息 | 两列“字段 / 值”；计划名称、说明、类型、开始时间、适用的结束时间、启用状态、跳过周末、跳过节假日；附派生周期时长或周期天数供阅读 |
| 子任务（操作） | 序号、任务内容、开始偏移（分钟）、持续时间（分钟），然后追加扩展列；保留原有排序与相对时间 |
| 周期项（巡视） | 周期第几天、时间、目标、人员、车辆、其他，然后追加扩展列；沿用现有六个表头名称 |

- 导入模板不包含示例业务记录，避免误导入；只有表头及必要说明，说明不混入数据行。
- 操作导入以任务内容、开始偏移、持续时间为必需列，序号可选；有序号则按其确定顺序，无序号按文件行序。数值规则沿用计划明细校验，偏移非负、时长大于 0。
- 有名为“子任务”或“周期项”的明细页时优先读取对应页，否则兼容仅含一个明细工作表的现有模板。不得把“计划信息”页当成明细猜测解析。
- 表头按名称映射，允许调换顺序；缺失或重复必需表头拒绝导入。可选序号或扩展列出现重名也要报歧义，不能随机取一列。
- 扩展列来自明细扩展键的并集，已对应固定业务列的键不重复输出；列顺序稳定，同一列在各行不存在值时留空。
- 扩展键与固定表头同名时加“扩展：”前缀直到唯一；数字、布尔等单元格保留对应值，复合字段值序列化为该扩展列的单元格文本，不把整个 extData 合成一列。
- 操作导入可接收唯一命名的附加扩展列并保留单元格标量，不自动把文本解析成任意 JSON。巡视导入继续按现有业务字段处理，扩展列恢复不作为本轮必需能力。
- 相近字段尽量采用相同表头和单位；不承诺所有导出文件可无损回导，不为非强制回导新增复杂映射向导。
- 显示文件内容时始终使用文本，不把任务内容或扩展值当作 HTML；导出文本不能被意外编码为可执行公式。

## 6. 大屏操作区域

- 保留当前操作卡片高度和单条时间轴，不添加计划轮播、多轨道或新的占高标题栏。
- 有可展示实例时仍使用原时间轴；无选择、计划禁用、已删除或当前窗口无实例时，在同一区域居中显示精确文案 `无可展示计划`。
- 空态使用现有中性灰正文样式，不渲染红色报错、不改变其他模块高度。
- API 请求失败仍保留上一次成功快照及既有连接异常提示，不能把网络失败误报为“无可展示计划”。
- 原许可、巡视、其他表格继续固定行高、两行文字截断和整表滚动。

## 7. 通用交互、尺寸与可访问性

- 计划列表宽屏维持现有管理布局；低于现有 900px 断点时沿用单列布局。新增表单字段在窄屏单列排列。
- 弹窗宽度不超过 `min(640px, viewport - 36px)`，高度不超过 `100dvh - 36px`；标题和按钮区保持可见，内容区独立滚动。
- 所有输入有可见标签；必填项统一标识。错误置于对应字段下方，用文字说明，不只把边框染红。
- 弹窗打开后焦点进入第一个可操作字段，关闭后返回触发入口；Tab 限定在活动弹窗，Escape 在未提交时可关闭。
- 确认覆盖/替换步骤默认焦点放在取消或返回，不默认聚焦破坏性按钮。表单步骤支持键盘，最终确认必须是明确确认动作。
- 同一时刻只有一个弹窗步骤接受操作；后台列表与下层弹窗不可被键盘穿透点击。
- 只锁定正在发生写操作的目标和相关动作，不让导出失败或其他计划加载导致全管理页永久禁用。
- 每个动作独立管理 loading/error/result，不复用一个布尔值让“切换大屏”错误地触发“导入中”。
- 数据读取采用最后一次请求结果；切换目标、筛选日期、关闭弹窗后，旧请求不能覆盖当前目标或状态。

## 8. 组件改动边界

| 位置 | 实施范围 |

| `OperationManager.vue` | 当前大屏摘要、radio、菜单、单计划生成入口；不继续堆放完整生成弹窗逻辑 |
