# OpenSpec

本项目使用 OpenSpec 管理需求与变更。

- `specs/`：已归档变更对应的正式规范。
- `changes/`：正在讨论、设计或实施的变更。
- `changes/archive/`：已归档的变更记录。
- `reference/`：历史设计参考，可能包含已被后续设计替代的模型和接口，不作为当前实施指令。
